# Currency Converter

A simple and user-friendly Currency Converter web application that allows users to convert one currency into another quickly and easily.

## Features

- Convert currencies easily
- Simple and clean user interface
- Supports multiple currencies
- Fast and easy to use
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Currency Exchange API

## How to Use

1. Select the currency you want to convert from.
2. Select the currency you want to convert to.
3. Enter the amount.
4. Click the Convert button.
5. The converted amount will be displayed.
